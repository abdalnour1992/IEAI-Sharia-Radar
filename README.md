# IEAI Sharia Radar Research

محرك بحثي يومي لتطبيق مقترح الماجستير **تطوير مؤشر ديناميكي لحفظ المال باستخدام التعلم الآلي** على سوق الأسهم التركي. يحل محل لوحة العرض السابقة التي كانت تعرض تصنيفات وأرباحًا ومحفظة مولدة عشوائيًا.

## الحالة الحالية

- المحرك يحسب الأهلية المؤرخة، والمؤشرات الأربعة، واحتمال حدث خسارة محدد، والأوزان، والصفقات، والتكاليف، والتحقق خارج التدريب.
- الواجهة لا تعرض بيانات أو نتائج قبل رفع مدخلات فعلية وتشغيل التجربة.
- اختبارات البرمجية تستخدم بيانات مصطنعة معلنة؛ نجاحها **ليس إثباتًا لفرضيات الرسالة**.
- جُلِبت السلاسل الرسمية للسعر والعائد الكلي للمؤشرين المرجعيين: 1,066 جلسة من أكتوبر 2021 حتى ديسمبر 2025، مع ضبط السوق ومرجع TLREF المحاذى.
- جُلِبت مرفقات المراجعات الدورية الثماني للعضوية. ما زال الافتتاح والاستمرارية الاستثنائية والإفصاحات ورأس المال وعوامل FF3/FF5 المحلية بحاجة إلى بيانات ومراجعة؛ لا تعتبر الحزمة بحثًا مكتملًا.
- لا تعلن البرمجية امتثالًا معتمدًا من IEAI أو جامعة مرمرة، ولا تؤكد الفرضيات تلقائيًا.

## التشغيل السحابي

GitHub Actions ينفذ `Research integrity and application tests` على Python 3.12 و3.13، بما فيه اختبارات Streamlit ومحاكاة كاملة ببيانات اختبار معنونة بوضوح. مخرجات الاختبار تحمل اسم `software-test-only-not-empirical`.

Workflow `Acquire exploratory historical market data` يجلب أسعارًا تاريخية فعلية عند تشغيله من Actions، ويسجل إخفاقات المزود دون استبدالها بأرقام عشوائية. الرمز الرسمي للمشاركة 100 هو `XK100`، ورمز Yahoo المطلوب `XK100.IS` **يخضع للتحقق من توافره**؛ لا يُستبدل بمؤشر `XKTUM` المختلف.

Workflow [Acquire and verify actual official research sources](.github/workflows/official-sources.yml) يجلب السلاسل من البورصة مباشرة، ويحفظ الردود الأصلية والبصمات ومرشحات العضوية وتقرير النواقص. يتجاوز نقص Yahoo، ويختبر محاذاة مرجع النقد مقابل حاسبة البورصة. تفاصيل النتائج ومسار الإغلاق في [DATA_ACQUISITION.md](docs/DATA_ACQUISITION.md)، و[طلب البيانات بالتركية](docs/DATA_REQUEST_TR.md).

توجد أوامر fetch-official وcompile-intake وaudit-coverage لجلب المصادر وترقية السجلات المراجعة وفحص التغطية. الأسهم القائمة تتطلب effective_from بالإضافة إلى available_at؛ FF3 وFF5 لهما ملفات مستقلة لأن بناء SMB يختلف بينهما.

لإجراء تجربة على بيانات موثقة، استخدم الواجهة أو CLI في بيئة سحابية:

```bash
python -m pip install -r requirements.txt
python -m ieai.cli validate --dataset data/reviewed --protocol config/protocol.json
python -m ieai.cli run --dataset data/reviewed --protocol config/protocol.json --output outputs/research
streamlit run app.py
```

## المدخلات والمخرجات

قوالب CSV وبيان المصادر في `examples/input-templates/`. التفاصيل في [DATA_CONTRACT.md](docs/DATA_CONTRACT.md).

الناتج: تقرير JSON، الأهلية والأسباب، المؤشرات، احتمالات الخسارة والدرجات، سجل التدريب، الأوزان اليومية، سجل الصفقات، نتائج المقارنة، وإحصاءات التقييم. يجمع `experiment.zip` الملفات مع بصمات SHA-256.

الملفات الكبيرة أو بيانات المستخدم لا تُرفع تلقائيًا إلى Git؛ ينفذ المحرك على الحزمة المختارة ويصدر نتائجها.

## المنهجية

راجع [RESEARCH_PROTOCOL.md](docs/RESEARCH_PROTOCOL.md) للتعريفات وقرارات التصميم والفروق عن المقترح، و[REQUIREMENTS_TRACEABILITY.md](docs/REQUIREMENTS_TRACEABILITY.md) لمطابقة متطلبات الرسالة، و[DATA_ACQUISITION.md](docs/DATA_ACQUISITION.md) للمصادر ونواقص التغطية.

تُثبّت الإصدارات المباشرة في requirements؛ وتُسجّل الإصدارات الفعلية والبصمات والبروتوكول في كل تجربة. CI يصدر أيضًا قفلًا للإصدارات الفرعية المستخدمة.

## حدود التفسير

درجة 75 لا تعني 75% امتثالًا شرعيًا أو ضمان حفظ المال؛ إنها `100 × (1 − احتمال الحدث المعرّف)` بعد تدريب ومعايرة. وقد يؤدي تقليل المخاطر إلى عائد أقل. تعرض البرمجية هذه المقايضة بدل فرض تفوق المحفظة.

هذه نسخة بحثية أولى، يومية، دون ربط بحساب وساطة أو تنفيذ أموال حقيقية. البرنامج يتيح الدراسة؛ صلاحية استنتاجاتها تتوقف على مراجعة البيانات والمنهجية والنتائج.
