# مطابقة متطلبات الرسالة

| المتطلب | التنفيذ | تحقق البرمجية وحدود الدليل |
|---|---|---|
| أكتوبر 2021 حتى ديسمبر 2025 | config/protocol.json | فصل بدء الدراسة عن بدء التقييم بعد التدريب |
| الأهلية الدورية والديون | ieai/screening.py | تاريخ النشر والسريان والانتهاء، وعدم اعتبار النقص صفرًا |
| المؤشرات الأربعة | ieai/features.py | تغيير بيانات المستقبل لا يغيّر المؤشرات السابقة |
| Random Forest | ieai/learning.py | عينات مؤرخة، labels ناضجة، فصل ومعايرة، frozen holdout |
| درجة 0-100 | ieai/learning.py | تعريف صريح لاحتمال حدث خسارة، لا أحكام شرعية |
| الأوزان المتكيفة | ieai/portfolio.py | أهلية مستقلة، حدود تركيز، سياسة تعرض معلنة |
| الاختبار الرجعي | ieai/backtest.py | التنفيذ التالي، الحساب الذاتي التمويل، تكاليف البيع والشراء |
| المؤشرات المرجعية | ieai/experiment.py | تحقق التغطية والعملة والسعر مقابل العائد الكلي |
| FF3 وFF5 | ieai/econometrics.py | مدخلات مستقلة لتعريف SMB؛ HAC وcross-check بـstatsmodels؛ لا نموذج بلا عوامله |
| مؤشرات العائد الكلي وضبط السوق | ieai/official.py | بيانات رسمية فعلية؛ محاذاة TLREF مقابل حاسبة البورصة؛ فشل المصدر مسجل |
| استكمال المدخلات وتغطيتها | ieai/intake.py وieai/coverage.py | سجل مصدر لكل قيمة؛ منع الاحتياطي/التغيرات دون لقطة افتتاحية؛ منع صفر القيم المجهولة |
| انحدار البانل | ieai/econometrics.py | إزالة تأثيرات الشركة والتاريخ، تحقق مستقل مقابل dummy regression؛ ارتباط لا سببية |
| التقارير | ieai/experiment.py | JSON وCSV وبصمات، لا نتائج ثابتة أو ضمان تفوق |
| العربية والتركية والإنجليزية | app.py | اختبارات AppTest، زر تشغيل مرتبط بمحرك فعلي |
| تشغيل GitHub السحابي | .github/workflows | اختبارات، إخراج test-only، وجلب سوق فعلي دون بدائل عشوائية |

## فجوات تتطلب بيانات وقرارات بحثية

الأسعار والعضوية والإفصاحات والعوامل التاريخية المراجعة لم تُعتبر موجودة لمجرد كتابة الكود. تقرير الجلب يوضح حدود المزود والملفات الناقصة. لا تحتوي هذه النسخة على نتائج بحثية منشورة أو تأكيد لفرضيات الرسالة.

التأصيل الفقهي الكامل، إثبات أصالة البحث، قياس سلوك القطيع سببيًا، واستنتاج تأثير المقاصد على الاستقرار النظامي لا تنتج تلقائيًا من RF أو نجاح الاختبارات. تُراجع هذه الاستنتاجات أكاديميًا ضمن الرسالة.
