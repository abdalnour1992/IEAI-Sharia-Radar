## الإفصاحات والأسهم القائمة

المصدر الأساس KAP/قوائم الشركات الأصلية، مع وقت النشر ورقم الإفصاح والفترة والوحدة والنسخة وموقع المبلغ في التقرير أو الإيضاح. يلزم تصنيف الديون ذات الفائدة والأصول ذات الفائدة والإيراد غير المتوافق والنشاط وبقية شروط الأهلية. لا يُغلق ذلك بإجمالي الالتزامات أو قوائم الشركة الحالية.

تتوفر الآن سجلات مصدر ومستورد يرفض القيم غير المراجعة والناقصة، ويتحقق من توافق الأسهم مع وحدات السعر والحجم، ويمنع تطبيق زيادة رأس المال قبل سريانها. إعادة عرض فترة قديمة لا تمحو أحدث فترة مالية/رأس مال معروفين. التغطية الفعلية لجميع الشركات والإجراءات الرأسمالية لم تُجلب.

[وثيقة KAP الرسمية](https://kap.org.tr/tr/api/about/content-file/8a019492945fbe080194b26d8bed4873) توضح أن طلبات البيانات الكثيفة تكون عبر خدمة التوزيع المرخّصة بعد العقد والتخويل. لم يُجرَ سحب كثيف لملفات الشركات من الواجهة العامة، ولم يُفترض اشتراك غير موجود. البديل تصدير مرخص من الجامعة/مزود بيانات أو ملفات أصلية مع أوقات النشر والدليل.

## عوامل السوق

market_factors.csv جُلِب فعليًا: العائد الكلي لـBIST 100 مطروحًا منه مرجع TLREF المحاذى، ومرجع النقد نفسه، بعوائد عشرية يومية TRY. يتيح CAPM، ويظهر غياب FF3/FF5 صراحة.

SMB/HML/RMW/CMA المحلية ليست ضمن حزمة المصادر التي جُلِبت. يلزم الحصول عليها بمصدر تركي موثق أو بناؤها من كون سوقي تاريخي أوسع من أسهم المشاركة، مع أسعار وأسهم وقيم دفترية وأرباح تشغيلية وأصول للفترات السابقة وتواريخ نشرها. تُعلن حدود الفرز والأوزان وإعادة التكوين والشطب ومعالجة TMS 29 قبل الاختبار النهائي. مدخل FF3 مستقل عن FF5 لأن SMB التقليدي وSMB الذي يجمع فرز القيمة والربحية والاستثمار مختلفان؛ راجع [تعريفات المؤلف](https://mba.tuck.dartmouth.edu/pages/faculty/Ken.french/Data_Library/f-f_5_factors_2x3.html).

## التنفيذ وإغلاق البيانات

داخل GitHub Actions شغّل Acquire and verify actual official research sources. الحزمة تحتوي CSV والردود الخام ومرشحات العضوية والتقرير والبصمات. ليست ZIP إدخال جاهزًا للتطبيق، ولن تعتبرها البرمجية بيانات بحث مكتملة.

    python -m pip install -r requirements.txt -r requirements-acquisition.txt
    python -m ieai.cli fetch-official --output outputs/official-sources-new
    python -m ieai.cli compile-intake --source data/reviewed-source-ledgers --output data/compiled-new
    python -m ieai.cli audit-coverage --dataset data/compiled-new

مجلد الإخراج جديد وفارغ، حتى لا تستمر ملفات قديمة بعد فشل المزود. راجع اكتمال الافتتاح والاستمرارية والإفصاحات ورأس المال والعوامل ثم تقرير التغطية وتوافق الوحدات. reviewed إقرار من معد البيانات؛ لا يصدر البرنامج شهادة أصالة ولا يثبت فرضيات الرسالة. طلب البيانات اللازم لإغلاق العوائق في [DATA_REQUEST_TR.md](DATA_REQUEST_TR.md).
